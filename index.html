ABOUT

Why a fixed menu?

A fixed menu is always on screen, so a visitor can jump to any part of the page without scrolling back up. I wrote it as an internship task to practise HTML, CSS and JavaScript together.

HOW IT WORKS

Three parts, three jobs

❮❯

HTML

Builds the structure: the logo, the menu button and the list of links.

✦

CSS

Sets the colors, the hover effect and the layout for phone and desktop.

↕

JavaScript

Watches the scroll position and changes the navbar color and active link.

TOOLS

Nothing extra needed.

The whole project runs from three files and a browser. There are no libraries or frameworks.
